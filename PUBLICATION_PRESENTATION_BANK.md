# Publication And Presentation Bank

This file tracks Kevin's fuller CV-style publication, presentation, award, and talk inventory. Use it when a tailored resume should become more CV-like, when a research role values publication/presentation evidence, or when a cover letter/interview prep note needs supporting specifics.

Do not treat this file as a mandate to include everything. For ordinary three-page resumes, prefer the compact `publication_ids` in `RESUME_BULLET_BANK.md`. Pull from this file only when the JD rewards academic/research visibility, invited talks, conference posters, grant/funding credibility, or scientific communication.

## Content Boundaries

- For public resume generation, use the top-level banks as the source of truth. Older local archives require deliberate promotion into the banks before use.
- MachineSaidGo may be referenced as Kevin's LLC / exploratory side-project umbrella when strategically useful and supported by canonical content.
- Unpublished manuscripts and internal presentations are evidence of project work and scientific communication, not publication claims.
- Internal CVB presentations can support bullets, audit reasoning, or cover letters, but usually should not appear as resume line items unless the role is explicitly research-leadership, program-leadership, or CV-like.
