## Answer Discipline

For each question, provide one best default answer. Kevin can elaborate in conversation, but the prep file should make the first landing easy.

- HR screener answers: target 30-45 seconds.
- Hiring manager answers: target 60-90 seconds.
- Default structure: direct answer -> concrete example -> outcome/lesson -> tie back to role.
- Prefer people -> problem -> decision -> outcome -> mechanism over mechanism-first explanations.
- Include one optional backup angle only when it would materially help.
- Include a short "stop after" cue when the answer is prone to over-expansion.
