# Profile Bank

This file is the canonical source for reusable resume headline/profile options.

Use one profile/headline pair as the starting point for a tailored resume, then lightly edit it for the target job description. Do not create a new profile for every job. Create a new retained cluster only when the JD requires a materially distinct positioning frame that existing clusters cannot cover.

The old DOCX profile bank can be regenerated for viewing if useful, but this Markdown file is the source of truth because it can be diffed, reviewed, and updated cleanly.

## Profile Cluster Update Rules

- Start from the profile whose core cluster best matches the JD.
- Use JD archetype add-ons to tune emphasis, not to choose the cluster by themselves.
- Surface and defend every meaningful profile/headline edit in the tailored resume audit.
- Mark single-JD clusters as `Provisional` rather than discarding them.
- Add reusable profile language here only when it strengthens future tailoring beyond one application.
- Keep one-off customization in the tailored resume and audit, not in this bank.
